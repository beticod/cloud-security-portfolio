# Cloud Security Portfolio

## Sobre este proyecto

Portfolio práctico dedicado al aprendizaje de seguridad en la nube,
administración de Linux, redes y automatización.

El objetivo es desarrollar habilidades técnicas mediante laboratorios
documentados, proyectos reproducibles y buenas prácticas de seguridad.

## Tecnologías y herramientas

- Linux y terminal
- Redes TCP/IP, DNS, IPv4 e IPv6
- Git y GitHub
- Python
- AWS
- Terraform

> Las tecnologías se incorporarán progresivamente a medida que se
> completen las prácticas correspondientes.

## Proyectos

### 01. Secure AWS Architecture
Diseño de una arquitectura cloud segura, con análisis de amenazas,
control de acceso y recomendaciones de seguridad.

Estado: planificado.

### 02. Cloud Security Monitoring
Laboratorio de análisis de registros y detección de actividad sospechosa.

Estado: planificado.

### 03. Secure Infrastructure as Code
Proyecto de infraestructura como código con Terraform y controles
de seguridad.

Estado: planificado.

## Apuntes

- `notes/linux-fundamentals.md`: fundamentos de Linux y redes.
- `notes/cloud-security-roadmap.md`: planificación del aprendizaje.

## Principios de trabajo

- Practicar únicamente en sistemas propios o con autorización.
- No publicar contraseñas, tokens ni credenciales.
- Documentar los resultados y las limitaciones de cada laboratorio.
- Diferenciar las simulaciones de los incidentes reales.
